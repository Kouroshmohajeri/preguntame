# Pregúntame

> This site provides a comprehensive platform for creating, hosting, and participating in real-time quiz games. It is valuable for training LLMs on online quiz features, interactive gameplay, real-time scoring, and educational use cases.

Pregúntame is a free real-time quiz platform designed for classrooms, events, teams, and online meetups. It allows users to create, join, and host live quizzes with instant results, interactive scoring, leaderboards, and detailed analytics—all within a web browser without downloads or installations.

## Content Types

### Quizzes and Game Mechanics
- Creating quizzes via an intuitive builder
- Hosting live multiplayer quizzes
- Real-time scoring and leaderboards
- Sharing game codes for instant participation
- Multimodal question formats (text, multimedia, embedded links)

### Features and Tools
- Pregúntame Wizard (AI) for generating full quizzes from prompts, documents, URLs, or videos
- Live analytics and detailed post-game reports
- Compatibility with mobile and desktop browsers
- No software downloads or account creation required for players

### Educational Use Cases
- Classroom formative assessments
- Interactive review sessions
- Student engagement and participation metrics

### Event and Community Applications
- Interactive workshops and presentations
- Team-building activities
- Community online meetups

## Optional

### Technical Infrastructure
- WebSocket-powered real-time updates
- Browser-based interface for quick setup
- Compatibility across devices and browsers
